# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately** through GitHub's private vulnerability reporting:

1. Go to [github.com/theneev/nizivo/security/advisories/new](https://github.com/theneev/nizivo/security/advisories/new).
2. Describe the issue, the affected package and version, and how to reproduce it.

Do not open a public issue, pull request or discussion for a suspected vulnerability. We will confirm receipt, keep you updated while we investigate, and credit you in the advisory unless you ask us not to.

## Supported versions

Nizivo is pre-1.0. Only the latest published 0.x release receives security fixes.

| Version            | Supported |
| ------------------ | --------- |
| Latest 0.x release | Yes       |
| Older 0.x releases | No        |

No version has been published yet.

## Scope

This policy covers the published packages (`@nizivo/tokens`, `@nizivo/react`, `@nizivo/icons`) and this repository's build and release pipeline. Report vulnerabilities in a dependency, such as React Aria, to that project; tell us too if Nizivo is affected.
