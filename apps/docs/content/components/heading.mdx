## Static or interactive

**Server.** It ships no client JavaScript when a Server Component renders it, in every Next.js build
mode; its code is bundled only when a client component (a `'use client'` file) imports it. [How to
choose](/docs/guides/static-or-interactive/).

## Tones

`tone="accent"` is deprecated: it paints `--nz-text-brand`, exactly as `tone="brand"` does, since
Figma has no accent text for page surfaces (M38). Use `tone="brand"`. It keeps working, with no
visual change; its removal is deferred to 1.0, or to when Figma adds an accent text for page
surfaces. Accent text on `bg/inverse` is `--nz-text-inverse-accent`. Card's and KpiTile's
`tone="accent"`, a surface rather than a text colour, is not deprecated.
