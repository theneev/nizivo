title: NumberValue
description: A number formatted once with `Intl.NumberFormat`, in a `<data>` element whose `value` attribute keeps the raw number. Tabular figures, so a column of values lines up. Every dashboard part renders its numbers with it.

## Static or interactive

**Server.** It ships no client JavaScript when a Server Component renders it, in every Next.js build
mode; its code is bundled only when a client component (a `'use client'` file) imports it. The text is formatted on the server with `Intl.NumberFormat(locale, format)`; `formatNumber`, exported
from the same subpath, returns the same text, so CountUp's client frames end on exactly the server's
string. [How to choose](/docs/guides/static-or-interactive/).
