## Static or interactive

**Server.** It ships no client JavaScript when a Server Component renders it, in every Next.js build
mode; its code is bundled only when a client component (a `'use client'` file) imports it. The chart arrives as an element (`chart={<Sparkline … />}` from `@nizivo/charts`, which ships
no client code either); `@nizivo/react` never imports `@nizivo/charts`. [How to
choose](/docs/guides/static-or-interactive/).

In a client app (a Vite or React Router single-page app, or a `'use client'` file) it is an ordinary React component: event handlers, refs and state work as usual. [In a client app](/docs/guides/static-or-interactive/#in-a-client-app).

See [Dashboard](/docs/dashboard/) for the status contract, a Suspense example and charts through
slots.

## Tones

`tone` is `surface` (the default), `brand` or `accent`: Card's surfaces, chosen for the row, not
from the sign of the change.

- On `brand` and `accent` the Delta pill is `bg/surface` rather than Figma's `bg/success-subtle`,
  which is the same green-50 as the `brand` tint and would show no fill. A deviation from Figma 04
  (gap 4), chosen by the maintainer (M42); see [Card](/docs/components/card/#tones).
- In dark mode `brand` and `accent` are both green-950, so they look the same. That is Figma's
  design, followed for now (Figma 04 issue 5; M42).
- The tile is a Card, so it declares `--nz-surface`: a Sparkline in `chart` draws its end-dot halo
  in the tile's colour, not as a white ring ([Card](/docs/components/card/#the-surface-variable)).
