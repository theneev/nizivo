**Client.** It always ships React Aria's tabs code (+38,812 B gzip under Turbopack for one Tabs on

## Direction

The strip's direction comes from the `NizivoConfig` scope: under a right-to-left `locale` (Arabic,
Hebrew, Persian and so on) the layout and the arrow keys follow it, and ArrowLeft moves to the next tab.
A strip whose direction differs from its locale's sets `dir` on `Tabs.Root`, which wins over the
scope:

```tsx
<NizivoConfig locale="de-DE">
  {/* a strip of Arabic labels inside a German page */}
  <Tabs.Root dir="rtl" defaultValue="overview">
    …
  </Tabs.Root>
</NizivoConfig>
```

`dir` takes `'ltr'` or `'rtl'` and is rendered as the root's `dir` attribute. Without it, nothing is
rendered and the nearest `Tabs.Root` around the strip that sets `dir` decides, so a strip nested in
its panels keys the way CSS lays it out; with none, the locale decides. Nothing reads the page's DOM,
so a `dir` attribute on any other ancestor does not turn the arrows, and `'auto'` is not accepted.
The override covers the tab list's keys only: the tab labels and the panels keep the scope's locale
(a number formatted in a label stays in it), and a Menu, Select or Tooltip inside a panel takes its
direction from `NizivoConfig`.
