---
title: ProgressBar
description: A native progress bar for a task or goal, determinate or indeterminate, with a visible label and value.
---

## Static or interactive

**Server.** It ships no client JavaScript when a Server Component renders it, in every Next.js build
mode; its code is bundled only when a client component (a `'use client'` file) imports it. The
indeterminate bar is a CSS animation. [How to choose](/docs/guides/static-or-interactive/).
