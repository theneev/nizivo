## Static or interactive

**Server.** No client JavaScript: the row is a link (`href`, or `render` for a router link).
[How to choose](/docs/guides/static-or-interactive/).

## Content

`title` says what happened, `detail` adds a quote or a figure and `time` when (a `<time>` is
best). `avatar` takes an [Avatar](/docs/components/avatar/), decorative since the title names the
person. `unread` tints the row, adds a dot and starts its name with "Unread" (`labels.unread`), so
the state is never the tint alone.
