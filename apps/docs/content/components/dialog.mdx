---
title: Dialog
description: A modal dialog or alert dialog with a trigger, title, description, body, footer and close parts. Focus moves in on open and returns to the trigger on close.
apg: https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/
keyboard:
  - keys: Enter, Space
    action: On the trigger (a button), opens the dialog and moves focus to the first focusable element in its body, or to the dialog itself when the body has none. An alertdialog focuses its Close button; a control with autoFocus wins.
  - keys: Tab, Shift+Tab
    action: Moves focus between the focusable elements inside the dialog; focus stays inside while it is open.
  - keys: Escape
    action: Closes the dialog (also an alertdialog) and returns focus to the trigger.
keyboardSource: react-aria-components 1.22.1 `ModalOverlay` and `Modal` (react-aria 3.53.1 `useModalOverlay`, which contains focus) through `_engines/react-aria/dialog.client.tsx`. React Aria focuses the dialog element; the first-focusable rule is Nizivo's (`initialFocus` on the engine seam, ARCHITECTURE.md §12.2), checked by the overlay lane (`test/overlay/dialog.spec.tsx`). apps/docs/scripts/smoke.ts checks opening with Enter, Tab staying inside, and Escape closing with focus back on the trigger; the Next fixture checks Escape and the Close part. An alertdialog does not close on an outside press.
