title: Delta
description: A signed change, such as +12.4%, coloured by direction and read with a visually hidden comparison. The sign carries the direction without colour.

## Static or interactive

**Server.** It ships no client JavaScript when a Server Component renders it, in every Next.js build
mode; its code is bundled only when a client component (a `'use client'` file) imports it. The
number is formatted on the server with `Intl.NumberFormat`. [How to
choose](/docs/guides/static-or-interactive/).

In a client app (a Vite or React Router single-page app, or a `'use client'` file) it is an ordinary React component: event handlers, refs and state work as usual. [In a client app](/docs/guides/static-or-interactive/#in-a-client-app).

## On a tinted surface

Inside a Card, KpiTile or TrendCard with `tone="brand"` or `tone="accent"`, the pill is
`bg/surface`, because the design's `bg/success-subtle` is the same colour as `bg/brand-subtle` and the
pill would show no fill there (a deliberate departure from the design, M42). Its text colour, and so its
contrast, is unchanged. Set `--nz-delta-bg` to choose another fill.
