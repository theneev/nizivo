## Static or interactive

**Client.** It always ships React Aria's listbox and popup code and FieldScope (+72,949 B gzip under
Turbopack for one Select on the Next.js fixture). NativeSelect is the static alternative when the
browser's own picker fits. [How to choose](/docs/guides/static-or-interactive/).

## In a Field

Inside a `Field`, Select reads the Field the way Input does: the label and the selected value name
the trigger, the description and the error describe it, and the Field's `name`, `required`,
`disabled` and error state apply unless the Select sets its own (an explicit `false` wins). The
Field's `name` reaches the hidden native `<select>`, so the value is in `FormData`.

A click on the label focuses the trigger, with its focus ring, and never opens the list: a native
`<label for>` a button would press it. A required, empty Select stops the submit and takes focus,
but shows no inline message yet (React Aria handles the hidden `<select>`'s `invalid` event), so pass
`error` for it. The trigger is a button, which cannot carry `aria-required`, and the Field's `*` is
hidden from screen readers, so put "required" in the label or the description too (the maintainer's
rule for 0.1.0). A form reset puts
the default value back in the trigger and in the submitted data.

## The selected row

The selected row keeps a `--nz-bg-brand-subtle` tint, and its label turns Label/M Strong in
`--nz-text-primary`. A check at its end (`--nz-icon-brand`) carries the state for readers who do not
see the colour (WCAG 1.4.1). The check's 16 px column is reserved on every row, so selecting never
moves the text. `indicator` on `Select.Item` replaces the check, and `indicator={null}` removes it.
The design draws no tint on the selected row; the code keeps it (the maintainer's decision of
2026-10-18).

## The list

The list follows the design's Select Menu: `--nz-radius-md`, `--nz-elevation-4`, 6 px inside,
and 4 px below the trigger (`sideOffset` on `Select.Popup`). Rows are 36 px of Label/M with 8 / 12 px
padding and no gap between them, and the keyboard ring is drawn inside the row. Group labels are
Label/S in `--nz-text-secondary`, padded 8 / 12 / 4 / 12. A separator has 4 px above and below. The
Dropdown Menu (Menu) keeps its own look.

## Text size on touch screens

Under a coarse pointer (a phone or a tablet), the trigger's value and placeholder are 16 px (Label/L)
instead of 14 px (Label/M) at every size, matching NativeSelect, so swapping one for the other does
not change the text. The trigger keeps its 32, 40 or 48 px height. The list's rows stay at 14 px and
its group labels at 12 px: they are not text fields, so iOS does not zoom into them.
