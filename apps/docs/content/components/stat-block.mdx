## Static or interactive

**Server.** No client JavaScript. [How to choose](/docs/guides/static-or-interactive/).

## Use

`value` is the number, formatted, in tabular figures; `label` says what it counts; `delta` takes a
[Delta](/docs/components/delta/). Each block is a term and its value, so put a row of them in a
`<dl>`. Only real, sourced numbers: never round up for effect.
