title: Card
description: A surface with optional header, title, description, action, body and footer parts. The inverse tone flips every token inside it.
---

## Static or interactive

**Server.** It ships no client JavaScript when a Server Component renders it, in every Next.js build
mode; its code is bundled only when a client component (a `'use client'` file) imports it. Every
part is server-safe; a child you put in `Card.Action` ships whatever its own component ships. [How
to choose](/docs/guides/static-or-interactive/).
