---
title: NativeSelect
description: The browser's own select, styled like the Select trigger. Server-safe with no client code; use it where the native picker is the better choice, such as on phones or in Server Component forms.
keyboard:
  - keys: Tab
    action: Moves focus to the select.
  - keys: ArrowUp, ArrowDown, Space, Enter, Type a character
    action: The browser's own select keyboard, which differs by platform; typing jumps to the next option that starts with what you typed.
keyboardSource: a native `<select>` (`native-select.tsx`), which adds no key handling.
---

Placed directly inside a Field, or through a function child, a NativeSelect is wired as plain
attributes with no client code. It keeps the browser's own validation bubble rather than the Field's
inline message, so do not mix it with Field-wired client controls in one native-validated form (see
[Field](/docs/components/field/#validation-in-mixed-forms)).

## Text size on touch screens

Under a coarse pointer (a phone or a tablet), the value is 16 px (Label/L) instead of 14 px (Label/M)
at every size, as on the Select trigger, because iOS Safari zooms the page into a focused `<select>`
whose text is smaller than 16 px. The box keeps its 32, 40 or 48 px height.
`--nz-native-select-font` replaces the font on every pointer, so a page that sets it also decides
whether iOS zooms.
