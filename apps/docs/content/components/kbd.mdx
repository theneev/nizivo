## Static or interactive

**Server.** It ships no client JavaScript when a Server Component renders it, in every Next.js build
mode; its code is bundled only when a client component (a `'use client'` file) imports it. It
renders both platforms' keys and CSS shows one, from the `data-nz-platform` attribute that
ThemeScript sets; without ThemeScript the Ctrl spelling shows. [How to choose](/docs/guides/static-or-interactive/).
