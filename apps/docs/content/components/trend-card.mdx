## Static or interactive

**Server.** It ships no client JavaScript when a Server Component renders it, in every Next.js build
mode; its code is bundled only when a client component (a `'use client'` file) imports it. Its slots render what you pass: a client Select in `action` ships its own code, and an
`AreaChart` in `chart` ships the charts island. [How to
choose](/docs/guides/static-or-interactive/).

In a client app (a Vite or React Router single-page app, or a `'use client'` file) it is an ordinary React component: event handlers, refs and state work as usual. [In a client app](/docs/guides/static-or-interactive/#in-a-client-app).

## Tones

`tone` is Card's. On `brand` and `accent` the headline's Delta pill is `bg/surface` so it shows on
the tint, and the card declares `--nz-surface` for the chart to read
([Card](/docs/components/card/#tones)).
