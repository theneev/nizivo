[Legend](/docs/charts/legend/), [DonutChart](/docs/charts/donut-chart/) and

The example is the page's content only: in the app it goes inside
[AppShell](/docs/components/app-shell/), which owns the sidebar, the top bars and `<main>`.

```tsx
// app/(store)/layout.tsx: the shell wraps every store page; the page renders its content
import { AppShell } from '@nizivo/react/app-shell';

<AppShell sidebar={sidebar} topBar={topBar} mobileTopBar={mobileTopBar} tabBar={tabBar}>
  <AnalyticsPageExample />
</AppShell>;
```

## Notes

- **Heading levels.** This site's page already has its `<h1>`, so the example passes `level={2}` to
  PageHeader. In your app, drop `level` (the title becomes the page's `<h1>`).
- **Charts in cards.** Each chart's Card title names it on screen; the chart takes the same
  `title` with `titleVisibility="hidden"`, so its figure and its data table keep the name.
  The area, bar and donut charts load their small interaction island; the sparklines ship nothing.
- **The range.** The SegmentedControl submits `range` with a form, or drives the data from the
  client; the example leaves that wiring to your app.
- **Layout.** Figma's row widths (798 / 314, 524 / 588, 690 / 422) match no column span, so the
  report is two equal columns from 36rem, the three charts across both.
- **Not built.** Figma's Funnel chart ("Checkout funnel") and Heatmap ("Orders by hour") have no
  component in `@nizivo/charts`, so the example leaves both out and shows the sales trend in
  their place.
