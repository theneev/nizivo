## Notes

- **Usage is a Meter.** Figma draws a raw track; here it is a native `<meter>` named "Usage", whose
  `valueText` is shown and read as "310 of 500 used" instead of a bare percentage. Expired's data
  is corrected too: Figma's fill is 252 px in a 250 px track.
- **No limit.** Figma has no unlimited code. A meter needs a maximum, so the fourth card says its
  count in words ("1,284 used · no limit") instead.
- **Expired keeps its contrast.** Figma dims the whole Expired card with `opacity: 0.70`, which
  takes `text/secondary` to 3.25:1 and `text/tertiary` to 2.57:1. Here only the status Badge, the
  code and the meter turn neutral, and the words say "Expired" and "Ended"; the text stays at full
  contrast.
- **Dates.** Scheduled gets its start and the others their end, which Figma leaves out, through
  `Intl.DateTimeFormat` with an explicit time zone.
- **The code** looks copyable but is plain text. A copy button with a "Copied" announcement is a
  client island; add one beside the code in your app if you need it.
- **i18n.** The counts go through `Intl.NumberFormat`; `{used} of {limit} used` is one message for
  a translation, never concatenated numbers.
