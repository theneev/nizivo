---

It uses [Breadcrumb](/docs/components/breadcrumb/), [PageHeader](/docs/components/page-header/),
[Badge](/docs/components/badge/), [Button](/docs/components/button/),
[Split](/docs/components/split/), [Card](/docs/components/card/),
[Field](/docs/components/field/), [Input](/docs/components/input/),
[Textarea](/docs/components/textarea/), [ChipGroup](/docs/components/chip-group/),
[Fieldset](/docs/components/fieldset/), [Switch](/docs/components/switch/),
[KpiTile](/docs/components/kpi-tile/), [ProgressBar](/docs/components/progress-bar/) and
[Checkbox](/docs/components/checkbox/).

The example is the page's content only: in the app it goes inside
[AppShell](/docs/components/app-shell/), which owns the sidebar, the top bars and `<main>`.

```tsx
// app/(store)/layout.tsx: the shell wraps every store page; the page renders its content
import { AppShell } from '@nizivo/react/app-shell';

<AppShell sidebar={sidebar} topBar={topBar} mobileTopBar={mobileTopBar} tabBar={tabBar}>
  <ProductDetailPageExample />
</AppShell>;
```

## Notes

- **Heading levels.** This site's page already has its `<h1>`, so the example passes `level={2}` to
  PageHeader. In your app, drop `level` (the title becomes the page's `<h1>`).
- **One form.** Every field belongs to the form, and the header's Save submits it through its `form`
  attribute, so the button can sit outside the form.
- **Columns.** `Split` puts the aside beside the main column while the main column keeps at least
  60 % of the row, and stacks them below that, so on this site's narrow preview the aside sits under
  the main column.
- **Not built.** The design's media gallery has no component: the example draws the tiles in its
  stylesheet, with an "Add media" button where the design draws the upload tile (use
  [FileUpload](/docs/components/file-upload/) there). The design shows no sticky save bar for small
  screens; [StickyBar](/docs/components/sticky-bar/) is the part for one.
