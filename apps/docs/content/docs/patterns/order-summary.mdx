## Notes

- **Money.** `NumberValue` formats every amount with `Intl.NumberFormat` and the order's currency,
  so a zero-decimal currency or another locale needs no other change. Never build an amount by
  concatenating strings.
- **Line totals.** Figma shows the line's total with no unit price (05 §3.10); say so in a column
  header or a visually hidden word if your readers could take it for the unit price.
- **Totals.** A `<dl>`: each label is a `<dt>`, each amount a `<dd>`, read as pairs by screen
  readers. A discount row is a negative amount; give it words ("Discount") rather than colour alone.
