## Notes

- **Client JavaScript.** One plan is a server composition. The row adds a SegmentedControl, a
  client component; the prices switch through CSS on its native radios, so they work before it
  hydrates.
- **Featured is structure, Tier is data.** Figma's Tier axis (Basic, Grow, Scale) is content; the
  one structural difference is the featured plan, the only inverse card, with the accent CTA and a
  "Popular" Badge. In the dark theme `bg/inverse` is light, so the featured plan becomes the only
  light card; Card's inverse tone keeps every colour inside it in the inverse scheme. Figma's
  `Elevation/3 Popover` is for floating layers; the featured card takes elevation 1.
- **Price.** `{price} / month` is a `NumberValue` and a separate word, never one concatenated
  string, so a translation can reorder them and the amount keeps its tabular figures.
- **Features** are a `<ul>`. The icons are decorative; a feature the plan lacks says "Not
  included" in visually hidden text, as the cross alone would be colour and shape only.
- **The CTA** is a link drawn as a Button (`render={<a />}`): starting a plan goes to a page. Its
  name is "Start with Basic", unique per card.
- **Contrast.** Figma's tagline and "/ month" on the inverse card use `text/tertiary`, 4.03:1; here
  they are `text/secondary`, resolved in the inverse scheme.
