## Notes

- **One link per row.** The order number is a `Table.RowLink`, a stretched link: the whole row is
  its hit area and shows the hover, but the row is one Tab stop and the link's name is the order
  number. Never put `role="link"` on a `<tr>`.
- **Two statuses, in words.** Payment and fulfilment are separate Badges, as Figma draws them, and
  each says its state ("Paid", "Unfulfilled"); the tone only repeats the word.
- **The customer.** The Avatar is decorative because the name is printed next to it; without a
  photo it shows the initials, which Figma's raw ellipse could not.
- **Dates.** `Intl.DateTimeFormat` with an explicit locale and time zone, inside `<time dateTime>`,
  so the server and the browser print the same text and a locale picks its own 12 or 24 hour clock.
  Figma's "Oct 14, 09:12" is hard-coded English.
- **Money.** Totals are `NumberValue` in end-aligned tabular figures. A long currency needs no
  fixed column width: the table scrolls inside its named container rather than wrapping.
