## Notes

- **Heading levels.** This site's page already has its `<h1>`, so the example passes `level={2}` to
  PageHeader. In your app, drop `level` (the title becomes the page's `<h1>`).
- **Filters are URLs.** The status links, the search form (`?q=`) and the pages need no JavaScript;
  the server reads them and renders the matching rows. Sort is a Select; submit it with the search
  form, or move it into the URL from the client.
- **Selection.** Each row's checkbox submits its id with the "Archive selected" form through `form`,
  before any JavaScript runs; `TableSelection` adds the select-all box, Shift-click ranges and Escape.
- **Not in Figma.** Figma draws selected rows but no bulk-action bar, and a "…" row menu that is not
  designed; the example has one bulk action and leaves the row menu out.
- **Narrow screens.** The filters wrap under the tabs, and the table scrolls sideways inside the
  card. Figma has no mobile design for this page.
