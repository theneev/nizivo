## Install

```sh
pnpm add @nizivo/react@next @nizivo/tokens@next
```

Add React to Astro with `@astrojs/react`.

## Import the CSS once

In your base layout, import the tokens, the accessibility floor and the component stylesheets. Keep the
`.css` extension:

```astro title="src/layouts/Base.astro"
---
import '@nizivo/tokens/tokens.css';
import '@nizivo/react/css/base.css';
import '@nizivo/react/css/card.css';
---
<html lang="en" data-nz-theme="system">
  <body><slot /></body>
</html>
```

## Islands

- Components rendered without a `client:*` directive are static HTML and ship no JavaScript.
- Children passed from an `.astro` file arrive as static HTML. Compose a compound component (a
  `Select.Root` with its parts) inside one `.tsx` island.
- Props to a `client:*` island must be serialisable: no functions.
- Context does not cross islands.
