## Static or interactive

**Server.** ChartTooltip has no `'use client'` and imports no client module
(`island-graph.test.ts` in `packages/charts/test/unit`). It is only the card: showing it at a point,
placing it and announcing the point are the ChartInteraction island's job, which AreaChart and
BarChart render. The island imports this card, so a page with an interactive AreaChart or BarChart
ships it as part of the island's client graph (the island, this card and `cx`). [How to choose](/docs/guides/static-or-interactive/).

## Props

<ChartProps />

`ChartTooltipRow`: `label` (the series name), `value` (pre-formatted, Numeric/M, tabular) and
`series` (a `ChartSeries`, the swatch's colour role). `ChartTooltipDelta`: `value` (the change with
its sign, for example "+28.0%"), `label` (for example "vs previous") and `trend`
(`'up' | 'down' | 'flat'`); their members are under [Other exports](#other-exports). `delta` and
`delta.label` also accept `undefined`, so a computed value can be passed as it is under
`exactOptionalPropertyTypes`.

## CSS hooks

<ChartCssHooks />

`--nz-chart-tooltip-width` is the card's width (Figma: a fixed 200 px), and
`--nz-chart-tooltip-halo` the ring around the island's point dots: the surface behind the chart.
When the hook is unset, the ring takes the shared `--nz-surface` that `@nizivo/react`'s
[Card](/docs/components/card/) declares for its children (KpiTile and TrendCard are Cards, so a
tinted tile's halo is its own surface), else `--nz-bg-surface`. Charts read `--nz-surface` only if
it is there: without `@nizivo/react` on the page it is unset and the halo is `--nz-bg-surface`, and
`@nizivo/charts` does not depend on `@nizivo/react` (M42).

## Accessibility

- The rows are a description list: each series name is a `<dt>`, its value the `<dd>`. The swatch is
  `aria-hidden`.
- The sign of the change ("+", "−") carries its direction without colour.
- Inside the island the whole card is `aria-hidden`: the island's polite live region speaks the
  point, and the chart's data table carries every value. Rendered on its own, the card is ordinary
  text.
