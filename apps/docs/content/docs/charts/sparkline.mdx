## Static or interactive

**Server.** Sparkline has no `'use client'` and imports no client module
(`island-graph.test.ts` in `packages/charts/test/unit`); it has no interaction. The previews on this page import it
from the entry the Import section shows; with the barrel, this site's build (Turbopack) shipped no
chart JavaScript for them (2026-10-19). Under webpack without `optimizePackageImports` the charts
barrel has not been measured: prefer the subpath once it exists. [How to choose](/docs/guides/static-or-interactive/).

## Props

From `sparkline.tsx` in `packages/charts/src/sparkline` (`nz api` does not cover `@nizivo/charts` yet).
Sparkline also takes every attribute of `<span>` except `children`.

<ChartsTable label="Sparkline props">

| Prop    | Type                                         | Default          | Description                                                                                   |
| ------- | -------------------------------------------- | ---------------- | --------------------------------------------------------------------------------------------- |
| `data`  | `ReadonlyArray<number \| null \| undefined>` | required         | The values in order, evenly spaced along x. A value that is not a finite number leaves a gap. |
| `label` | `string`                                     |                  | An accessible name ("Sales, up 28% over 30 days"): the sparkline becomes `role="img"`.        |
| `curve` | d3-shape `CurveFactory`                      | `curveMonotoneX` | Any d3-shape curve.                                                                           |
| `area`  | `boolean`                                    | `true`           | The 10% wash under the line.                                                                  |
| `dot`   | `boolean`                                    | `true`           | The last value's dot.                                                                         |

</ChartsTable>

There is no `trend` prop: the trend is the last defined value against the first.

## Data attributes and slots

<ChartsTable label="Sparkline data attributes and slots">

| Element             | Attributes                                                                                                                   |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `span.nz-sparkline` | `data-slot="sparkline"`, `data-trend="up" \| "down" \| "flat"`; `aria-hidden`, or `role="img"` and `aria-label` with `label` |
| `svg.nz-chart-svg`  | `aria-hidden`: `path.nz-chart-area`, `path.nz-chart-line`, `path.nz-sparkline-halo`, `path.nz-sparkline-dot`                 |

</ChartsTable>

`up` and `flat` draw in `chart/primary`; `down` draws in `chart/neutral`.

## CSS hooks

<ChartsTable label="Sparkline CSS hooks">

| Hook                    | Default                | What it sets                                                 |
| ----------------------- | ---------------------- | ------------------------------------------------------------ |
| `--nz-sparkline-width`  | `7rem`                 | The width (Figma 03: 112 px; Figma 04's KPI tile uses 88 px) |
| `--nz-sparkline-height` | `2.25rem`              | The height (36 px; the KPI tile uses 28 px)                  |
| `--nz-sparkline-halo`   | `var(--nz-bg-surface)` | The ring around the end dot, for tinted surfaces             |

</ChartsTable>

## Accessibility

- Without `label`, the whole sparkline is `aria-hidden`: it is meant for a labelled context, such
  as a KPI tile whose Delta says the change. With `label`, it is one image with that name, and the
  name must say what the shape shows.
- Down is grey, not red (Figma 03's "down is not bad" rule); the colour is never the only signal.
- The line reveals by `clip-path` over `--nz-duration-chart-draw`, 0 ms under Reduced motion.
- The plot does not mirror in a right-to-left page: time runs left to right.
