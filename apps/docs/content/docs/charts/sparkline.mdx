## Static or interactive

**Server.** Sparkline has no `'use client'` and imports no client module
(`island-graph.test.ts` in `packages/charts/test/unit`); it has no interaction. The previews on this
page import it from `@nizivo/charts/sparkline`, and the docs smoke check fails any page outside the
AreaChart, BarChart and DonutChart pages that loads the charts island. Prefer the subpath to the barrel: under
webpack without `optimizePackageImports` the barrel has not been measured.
[How to choose](/docs/guides/static-or-interactive/).

## Props

<ChartProps />

`data` holds the values themselves (`data={[12, 14, 13]}`), or any data that `y` reads. `y` is an
`Accessor`, as AreaChart's: a key of the datum (`y="sales"`) or a `(datum, index) => value`
function, so one series can feed an AreaChart and a Sparkline. It is optional when the data are
numbers (`SparklineValue`, exported: a number, `null` or `undefined`), and TypeScript requires it
otherwise: `SparklineProps<T>` is a conditional type, which the table above lists as one optional
`y`. A value that is not a finite number leaves a gap.

There is no `trend` prop: the trend is the last defined value against the first.

## Data attributes and slots

<ChartsTable label="Sparkline data attributes and slots">

| Element             | Attributes                                                                                                                   |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `span.nz-sparkline` | `data-slot="sparkline"`, `data-trend="up" \| "down" \| "flat"`; `aria-hidden`, or `role="img"` and `aria-label` with `label` |
| `svg.nz-chart-svg`  | `aria-hidden`: `path.nz-chart-area`, `path.nz-chart-line`, `path.nz-sparkline-halo`, `path.nz-sparkline-dot`                 |

</ChartsTable>

`up` and `flat` draw in `chart/primary`; `down` draws in `chart/neutral`.

## CSS hooks

<ChartCssHooks />

`--nz-sparkline-width` and `--nz-sparkline-height` are the design's 112 × 36 px; the KPI tile
uses 88 × 28 px. `--nz-sparkline-halo` is the ring around the end dot: the surface behind the
sparkline. When the hook is unset, the ring takes the shared `--nz-surface` that `@nizivo/react`'s
[Card](/docs/components/card/) declares for its children (KpiTile and TrendCard are Cards, so a
tinted tile's halo is its own surface), else `--nz-bg-surface`. Charts read `--nz-surface` only if
it is there: without `@nizivo/react` on the page it is unset and the halo is `--nz-bg-surface`, and
`@nizivo/charts` does not depend on `@nizivo/react` (M42).

## Accessibility

- Without `label`, the whole sparkline is `aria-hidden`: it is meant for a labelled context, such
  as a KPI tile whose Delta says the change. With `label`, it is one image with that name, and the
  name must say what the shape shows.
- Down is grey, not red (the design's "down is not bad" rule); the colour is never the only signal.
- The line reveals by `clip-path` over `--nz-duration-chart-draw`, 0 ms under Reduced motion.
- The plot does not mirror in a right-to-left page: time runs left to right.
