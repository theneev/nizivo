## Static or interactive

**Server.** BarChart has no `'use client'` and imports no client module. Hovering a column dims the
other bars and shows that bar's tooltip in CSS alone. It passes `interaction="none"` to its
[ChartFrame](/docs/charts/chart-frame/): the plot has no Tab stop. The data table is the
screen-reader path; for sighted keyboard users, show it with `tableView="details"`.
[How to choose](/docs/guides/static-or-interactive/).

## Props

From `bar-chart.tsx` in `packages/charts/src/bar-chart` (`nz api` does not cover `@nizivo/charts` yet).
BarChart also takes every [ChartFrame](/docs/charts/chart-frame/) prop except `table`, `ticks`,
`axes`, `interaction`, `children` and `labels`, and every `<figure>` attribute.

| Prop             | Type                                         | Default                                                | Description                                                                                                                 |
| ---------------- | -------------------------------------------- | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `data`           | `readonly T[]`                               | required                                               | One bar per datum.                                                                                                          |
| `x`              | `(datum: T) => string`                       | required                                               | The category: an ISO plain date (formatted per `locale`) or a label, used as given.                                         |
| `y`              | `(datum: T) => number`                       | required                                               | The value. Not finite: no bar, and `labels.missing` in the table. Zero: no bar. Negative: the bar hangs from the zero line. |

| `format`         | `Intl.NumberFormatOptions`                   | `{ maximumFractionDigits: 0 }`                         | Values in the table and the tooltip.                                                                                        |
| `axisFormat`     | `Intl.NumberFormatOptions`                   | `format` in compact notation, 0 to 1 fraction digits   | The y labels.                                                                                                               |
| `dateFormat`     | `Intl.DateTimeFormatOptions`                 | `{ month: 'short', day: 'numeric' }`                   | ISO plain dates on the x axis.                                                                                              |
| `longDateFormat` | `Intl.DateTimeFormatOptions`                 | `{ weekday: 'short', month: 'short', day: 'numeric' }` | ISO plain dates in the tooltip title and the table.                                                                         |

## Accessibility

- The bars and the grid are `aria-hidden`; the server-rendered data table (one row per datum) is the
  accessible alternative. By default it is visually hidden and has no Tab stop, so it serves screen
  readers only: a sighted keyboard user cannot reach a bar's exact value. Pass
  `tableView="details"` to give everyone a native "Show data table" disclosure.
- The hover tooltip does not meet WCAG 1.4.13 (Content on Hover or Focus) yet: it cannot be
  dismissed with Escape, and moving the pointer onto it, beside the bar, hovers the next column.
  The ChartInteraction island's column mode, an open item, would close this.
- Hover is CSS only and makes no keyboard claim: the frame's `interaction` is `'none'`. A keyboard
  mode through the ChartInteraction island is an open item.
- Dimmed bars use opacity 0.35, not `chart/secondary` (§14.1); the hovered bar keeps
  `chart/primary`.
- Forced colours: bars draw in `CanvasText` (`Highlight` while hovered), grid lines in `GrayText`
  and the zero line in `CanvasText`. Only Chromium's forced-colours emulation has been looked at.
- No stagger in the reveal: a per-bar delay would need an inline style. All bars grow together over
  `--nz-duration-chart-draw`, 0 ms under Reduced motion.
