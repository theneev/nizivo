## Import

<ChartImport part="chart-frame" names="ChartFrame" />

The contract every renderer may rely on is `chart-frame.contract.ts` in `packages/charts/src/chart-frame`
(seam K9, §14.1).

## Static or interactive

**Server.** ChartFrame has no `'use client'` and imports no client module, so it ships no client
JavaScript when a Server Component renders it. The `tableView="details"` disclosure is a native
`<details>`, with no JavaScript. Its keyboard claim (`interaction`) is a statement about the child,
not code: ChartFrame itself adds no Tab stop except the disclosure's summary. [How to
choose](/docs/guides/static-or-interactive/).

## Props

From `chart-frame.contract.ts` and `chart-frame.tsx` (`nz api` does not cover `@nizivo/charts` yet,
so this table is written from the source). ChartFrame also takes every attribute of `<figure>`
except `title` and `children`, which it spreads on the root.

<ChartsTable label="ChartFrame props">

| Prop          | Type                                                                           | Default    | Description                                                                                                                                          |
| ------------- | ------------------------------------------------------------------------------ | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `title`       | `ReactNode`                                                                    | required   | The caption and the figure's accessible name; the data table is labelled by it.                                                                      |
| `summary`     | `ReactNode`                                                                    |            | One line under the title, for example "Daily sales, Oct 1–30, vs previous period".                                                                   |
| `table`       | `{ columns: readonly string[]; rows: readonly (readonly string[])[] }`         | required   | The data, pre-formatted. `columns[0]` heads the row-header column; each row's first cell is its `<th scope="row">`.                                  |
| `status`      | `'ready' \| 'loading' \| 'empty' \| 'error'`                                   | `'ready'`  | A ready chart whose `table` has no rows renders as `'empty'`.                                                                                        |
| `pending`     | `boolean`                                                                      | `false`    | A refresh is in flight while the chart shows data: `aria-busy` and `data-pending`.                                                                   |
| `tableView`   | `'hidden' \| 'details'`                                                        | `'hidden'` | `'hidden'`: visually hidden, read by assistive technology. `'details'`: a native disclosure under the plot.                                          |
| `axes`        | `'frame' \| 'none'`                                                            | `'frame'`  | `'frame'`: the frame draws the HTML tick labels from `ticks`. `'none'`: the child draws its own.                                                     |
| `ticks`       | `{ x?: readonly string[]; xAlign?: 'point' \| 'band'; y?: readonly string[] }` |            | `x`: one label per x position, `''` where no tick falls. `y`: from the top tick down to the baseline, evenly spaced. `xAlign` defaults to `'point'`. |
| `interaction` | `'nizivo' \| 'none'`                                                           | `'nizivo'` | `'none'` for a third-party child: the frame makes no keyboard claim for the points.                                                                  |
| `xDirection`  | `'ltr' \| 'rtl' \| 'auto'`                                                     | `'ltr'`    | See [Right to left](/docs/charts/#right-to-left).                                                                                                    |
| `legend`      | `ReactNode`                                                                    |            | A [Legend](/docs/charts/legend/), or any node, between the caption and the plot, in every status.                                                    |
| `empty`       | `ReactNode`                                                                    |            | Replaces the default empty message.                                                                                                                  |
| `error`       | `ReactNode`                                                                    |            | Replaces the default error message, for example an `InlineError` with a retry action.                                                                |
| `labels`      | `Partial<ChartFrameLabels>`                                                    |            | The frame's strings, below.                                                                                                                          |
| `render`      | `RenderProp<ChartFrameState>`                                                  |            | Replace or wrap the root element. A function receives `{ status, pending, interaction }`, with `status` as rendered.                                 |
| `children`    | `ReactNode`                                                                    |            | The renderer, which fills the plot. Rendered only while the status is `'ready'`.                                                                     |

</ChartsTable>

## Accessibility

- A `<figure>` named by its `<figcaption>`. The tick labels are `aria-hidden`: the data table
  carries the values.
- The data table is rendered on the server. With `tableView="hidden"` it is in the HTML only while
  the status is `'ready'`. With `tableView="details"` the disclosure renders in every status (an
  inert line until ready), so the frame's box does not move between statuses (§16.5).
- Loading sets `aria-busy` and renders visually hidden text (`labels.loading`). No status uses a live
  region (§16.5).
- `interaction="nizivo"` promises a keyboard path to the points, which a Nizivo renderer's island
  provides; `interaction="none"` promises none. `chart.conformance.tsx` in `packages/charts/test/conformance`
  checks every framed part for both claims, in all four statuses.
- The default table sits in a visually hidden wrapper, not hidden itself: a `<table>` ignores
  `inline-size: 1px`, so the wrapper's 1 × 1 clipped box is what keeps a wide table from adding
  horizontal overflow on a narrow screen (the charts-only fixture checks the 1 × 1 box).
- Focus: the charts stylesheet draws its own focus outline (`--nz-border-width-focus`, solid
  `--nz-border-focus`, 2 px offset) on any link, button, summary or `[tabindex]` inside a frame or
  a legend, so it does not need `@nizivo/react`'s base CSS.
