## Import

<ChartImport names="ChartFrame" />

The contract every renderer may rely on is `chart-frame.contract.ts` in `packages/charts/src/chart-frame`
(seam K9, §14.1).

## Static or interactive

**Server.** ChartFrame has no `'use client'` and imports no client module, so it ships no client
JavaScript when a Server Component renders it. The `tableView="details"` disclosure is a native
`<details>`, with no JavaScript. Its keyboard claim (`interaction`) is a statement about the child,
not code: ChartFrame itself adds no Tab stop except the disclosure's summary. [How to
choose](/docs/guides/static-or-interactive/).

## Props

<ChartProps />

`ChartFrameProps` in `chart-frame.contract.ts` (`packages/charts/src/chart-frame`) is the renderer
seam's contract; `ChartFrameElementProps` adds the `<figure>`'s attributes, and every chart's own
props include them too (one API shape across the charts, M40). With point-aligned labels
(`xAlign="point"`), an x position whose label is `''` renders an empty grid cell with no tick
element, except the last cell, which holds both edge labels: a long daily series sends hundreds of
empty positions. `xDirection` is explained under [Right to left](/docs/charts/#right-to-left).

### Hiding the caption

`titleVisibility="hidden"` hides the title and summary visually, for a chart whose container
already titles it, such as a card header (Figma's Revenue Card draws no chart caption). The default
is `"visible"`. The caption is not removed: the `<figcaption>` gets `nz-chart-visually-hidden` (a
1 × 1 clipped box out of flow, never `display: none`), so it takes no layout space, stays in the
server HTML, and still names the figure and its data table. Every chart takes the same prop
(`ChartFramePassthrough`, M40's one API shape):

```tsx
<AreaChart
  title="Revenue"
  summary="Daily, Oct 1–30"
  titleVisibility="hidden"
  data={days}
  x="date"
  y="sales"
/>
```

Keep `title` meaningful when it is hidden: it is still what a screen reader announces for the chart.

The English defaults of `labels` (`ChartFrameLabels`), in `chartFrameLabels`:

| Key       | Default                          | Where                                                   |

Classes a renderer draws with: `nz-chart-svg` (the percent-space SVG that fills the plot),
`nz-chart-grid`, `nz-chart-baseline`, `nz-chart-line`, `nz-chart-area` and
`nz-chart-visually-hidden`, with `data-series` on a mark (`current`, `previous`, `cat-1`, `cat-2`,
`cat-3`, `other`).

## CSS hooks

<ChartCssHooks />

`--nz-chart-frame-aspect` is the body's aspect ratio (18 / 7, Figma 03's 720 × 280 plot), and
`--nz-chart-frame-gutter` the y labels' column, which stays fixed in every status. Long localised y
labels can be wider than the 2.75rem gutter; widen it with the hook.

The frame is a size container (`container-type: inline-size`): a narrow chart adapts to its own
width, never the viewport's. Under 31rem, a body with axes is at least 12rem tall, so the plot keeps
about 10rem and the y labels their room (above that width the aspect ratio alone sizes it, a short
one of yours included). Under 25rem, the x axis shows every other label, counting only the
positions that have one, and always keeps the first and the last; the labels it hides are still in
the data table.

## Accessibility

- A `<figure>` named by its `<figcaption>`. The tick labels are `aria-hidden`: the data table
  carries the values.
- `titleVisibility="hidden"` keeps that name: the caption is visually hidden, not removed, so the
  figure is named the same and the table is still labelled by the title. The browser lane checks
  that the hidden caption takes no layout space and that the name does not change, in Chromium,
  WebKit and Firefox (`caption.spec.tsx`); `chart.conformance.tsx` checks that every framed part
  forwards the prop.
- The data table is rendered on the server. With `tableView="hidden"` it is in the HTML only while
  the status is `'ready'`. With `tableView="details"` the disclosure renders in every status (an
  inert line until ready), so the frame's box does not move between statuses (§16.5).
- Loading sets `aria-busy` and renders visually hidden text (`labels.loading`). No status uses a live
  region (§16.5).
- `interaction="nizivo"` promises a keyboard path to the points, which a Nizivo renderer's island
  provides; `interaction="none"` promises none. `chart.conformance.tsx` in `packages/charts/test/conformance`
  checks every framed part for both claims, in all four statuses.
- The default table sits in a visually hidden wrapper, not hidden itself: a `<table>` ignores
  `inline-size: 1px`, so the wrapper's 1 × 1 clipped box is what keeps a wide table from adding
  horizontal overflow on a narrow screen (the charts-only fixture checks the 1 × 1 box).
- Focus: the charts stylesheet draws its own focus outline (`--nz-border-width-focus`, solid
  `--nz-border-focus`, 2 px offset) on any link, button, summary or `[tabindex]` inside a frame or
  a legend, so it does not need `@nizivo/react`'s base CSS.
