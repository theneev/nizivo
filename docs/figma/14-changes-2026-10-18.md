## Summary

- **Dayitava mostly adopted what code had parked.** All 14 a11y colour overrides and all 18 code proposals are now real Figma variables or styles, with the same values as code. The 18 are neutral/450, neutral/925, red/400, blue/400, Body/S, Label/S, bg/scrim, bg/accent-hover, bg/critical-hover, text/on-critical, icon/info, border/control, border/control-hover, chart/warning, chart/critical, duration/fade, duration/pulse and scale/enter. Input, Select trigger, Checkbox, Radio, Switch, Button Critical/Accent, Alert, Badge, Delta, Skeleton radius, Modal and Kbd now match the shipped CSS.
- **Five things block 0.1.0:**
  - The dark chart/primary fill changed (Meter, ProgressBar, ProgressRing).
  - Five public chart tokens were recoloured for contrast.
  - border-width/strong was deleted, and Switch uses it.
  - The new Select option spec differs from the shipped popup.
  - The new Textarea spec is taller (112 px minimum) with more padding (12 px).
- **The next token pull cannot complete yet.** The rebuilt focus-ring styles bind colours to variables, and the normalizer throws on that (`packages/tokens/scripts/normalize/values.ts:42`). Every token fix needs a sync, so this fix comes first.
- **Two design decisions now contradict documented code decisions:**
  - duration/spin is 800 ms and stops under Reduced motion. Code uses 1000 ms and keeps turning.
  - The focus halo is a 4 px band at 16 % with a solid 2 px gap. Code shows a 2 px band at 28 % with a tinted gap. The 2 px outline itself matches.
- **The file was cleaned up.** Every off-canvas "ghost" master was deleted, and every instance now points at the on-canvas sets. Former ghost-only masters (Tooltip, Dropdown Menu, Drawer, Ranked List, the icons) now sit on pages. The component.json figma ids that pointed at the ghosts now point at nothing. That is repo metadata only and is not published.
- **Ten new pages:** Getting Started, 00 Icons, Accessibility, 11 Data Display, 12 Shaders & Motion, 13 Marketing, 14 Product Patterns, 15 AI, 16 Docs Site and a Website homepage. They add about 60 new components, none built. Most component pages also gained a Dark mode preview frame.
- **The Accessibility page sets rules that built code breaks:** required-field text, the Segment keyboard pattern and the reduced-motion spinner. The rewritten Tooltip description also asks for a delay on keyboard focus, which code does not have.
- **The design's own copy has errors.** The homepage and the Code Block master say `npm i @nizivo/ui` and `data-theme`. The repo uses `@nizivo/react`, `@nizivo/tokens` and `data-nz-theme`. The marketing numbers also disagree with each other (134 vs 114 components).
