## Deviations from Figma (kept on purpose)

- **Delta has no trend icon.** Figma draws trending-up and trending-down marks; Delta has no default glyph (consumers pass `icon` on their own `<Delta/>` through Metric's element slot). Adding a default pair is a Delta change, not this week's.
- **The Delta pill on `tone="brand"` does not show:** `bg/success-subtle` equals `bg/brand-subtle` (green-50), so the pill is 1.00:1 on the tint, exactly as Figma draws it. The sign and `text/success` (5.60:1 on the tint) carry the meaning.
- **Every tone keeps a transparent 1 px border**, so all KpiTile tones share one box (Figma: Surface 154 tall, Tinted 152).
- **TrendCard has no shadow at rest** (handoff row j); Figma's Revenue Card draws Elevation/1.
- **Pagination squares are 40 px (`md`) and 32 px (`sm`)** on the control scale rather than Figma's 36, with a 16 px icon rather than 18; `siblingCount` defaults to 1 (seven page slots), where Figma draws `1 2 3 … 13` (= `siblingCount={0}`).
- **Breadcrumb links are 24 px tall** (target size) where Figma's row is 20; nothing collapses in 0.2.
- **RankedList rows are 33.6 px** (Label/M is 19.6 px; Figma rounds to 20) and top-aligned; bars are SVG `<rect>`s rather than the inventory's `<meter>`; `RankedList.Action` is an addition (figma/04 issue 7).
- **AvatarGroup's name** uses `Intl.ListFormat`: "Maya, Jonah, Priya, and 4 more" (en-US Oxford comma) where Figma writes no comma.
- **DonutChart shows the ChartTooltip card** although Figma 03 §4.6 says "No tooltip is used. The centre label is the tooltip": M41 item 2 asked for the card; the centre swap is kept alongside it.
- **CountUp's easing** is 04 §5's proposed `easing/enter` curve, written into the code (Figma defines none for count-up), and a tile already in view at hydration keeps its server number instead of counting on load (04 §5 (a)); D-bg.
- **TrendCard below a 30rem header** (no Figma frame draws it): the action goes below the headline and the change below the number, so the comparison keeps its room at phone width; TrendCard fills its container (week 12 review A11Y-W12-3, D-bj).
- **A RankedList label is one line**, ending in an ellipsis when longer than its row (the reserved placeholder rows are one line; week 12 review A11Y-W12-4, D-bj).

## The week 12 review

Every fix was rerun in Chromium, WebKit and Firefox where it touches a browser.

- **A11Y-W12-1, major, fixed:** inside `@nizivo/react`'s own Dialog, Escape on a focused chart closed the whole dialog. React Aria's dialog wrapper handles Escape in a React `onKeyDown` on the popup, before the island's document listener could `preventDefault`, so only a native `<dialog>` stayed open. The layer's `onKeyDown` now takes Escape while the card shows (hides it, stops propagation, prevents the default) in all three island modes (+11 B on the island graph, 1,580 B, still inside 1.7 KiB); with focus elsewhere the document listener still hides a pointer-shown card without consuming the key (M41 item 1). `donut-chart-interaction.spec.tsx` adds a dialog that listens in React, as React Aria does (it fails without the fix, as does the native-dialog case); the reviewer's probe with the real Dialog now keeps it open in all three engines. `@nizivo/charts` has no `@nizivo/react` dependency, so the shipped case is the stand-in, not the Dialog itself.
- **A11Y-W12-2, major, fixed:** the §16.5 box test put the four statuses in one shared column, so it could not see a width change; with each status in its own `repeat(4, 1fr)` cell the error state widened its column (a one-line error, or one with a Retry) and at 200 % text the ready number did too. KpiTile, TrendCard and RankedList now take no minimum width from their content (`min-inline-size: 0`); the test renders each status alone at 200, 240, 320 and 480 px (TrendCard 320, 560, 800) at 100 % and 200 % text, with a bare fallback and an error with a Retry (55 cases, 17 of them failing before the fix). An enlarged number that does not fit now overflows the tile instead of widening it; the Dashboard page suggests a row minimum in `rem`. D-bj.
- **A11Y-W12-3, major, fixed:** at 320 px TrendCard's comparison shrank to 0 px and the default error to a few letters. TrendCard's header is now a size container: under 30rem (so enlarged text narrows it too) the action goes below the headline and the change below the number, and TrendCard always reserves the change row, so the box still matches across statuses.
