## API changes (private; semver'd from 0.2)

- **Shared** (`src/_core/api.ts`, exported as types from the barrel and the cartesian subpaths): `Accessor<T, V>` (a key of `T` whose values are `V`, or `(datum, index) => V`), `CartesianChartOptions<T>` (`data`, `x`, `y`, `locale`, `format`, `axisFormat`, `dateFormat`, `longDateFormat`, `xTicks`, `yTicks`), `ChartXTicks { every?; max? }`.
- **AreaChart:** `format`/`axisFormat` take `Intl.NumberFormatOptions` only (default `{}`, Intl's own); `xTickEvery` → `xTicks` (max 6); new `yTicks` (default 4). Removed: `AreaChartElementProps`, `ChartNumberFormat`.
- **BarChart:** `BarChartProps<T> extends CartesianChartOptions<T>` with the figure attributes, `interaction` (default `'nizivo'`) and `title`; `x`/`y` take a key or a function; `format` default `{}` (was `{ maximumFractionDigits: 0 }`, so fractional values now show); `xTicks.max` 8. `BarChartLabels extends ChartFrameLabels` and adds `interaction`, `hint` and `points`. Removed: `BarChartXTicks`.
- **DonutChart:** `category`/`value` are accessors; `format` default `{}`, `totalFormat` its compact form; `DonutChartLabels extends ChartFrameLabels`.
- **Sparkline:** `y` is an accessor, optional for data of plain values.
- **The island** (internal): `series`, `points` as tuples, `separators`, `delta`, `columns` (column mode); no `mirror`.

## The week 11 review

Three reviewers (accessibility behaviour; size, performance and visuals; API, docs and plan) filed 19 findings on the integrated tree: 17 fixed, 2 deferred with a reason (R2-4, R2-6), none rejected.

- **A11Y-W11-1, major, fixed:** the island read the plot's direction once, so a new `xDirection` on a live chart (a client re-render, or an RSC refresh that keeps the island mounted) left its keys, pointer and card reversed against the bars. AreaChart and BarChart now key the island by `xDirection`, so a new direction remounts it (0 island bytes). Two browser cases re-render ltr → rtl; both fail without the key.
- **A11Y-W11-2, major, fixed:** Escape moved to a document listener without `preventDefault`, so Escape on the focused plot inside a modal `<dialog>` also closed the dialog (week 10's `onKeyDown` did not). The listener now calls `preventDefault` when the event's target is the layer (+16 B). With focus elsewhere, Escape hides a pointer-shown card and still reaches the dialog (for the maintainer, below). Two browser cases, one of which fails without the fix.
- **A11Y-W11-3, major, fixed:** under forced colours the card inherited `forced-color-adjust: none` from the crosshair's column and kept its author colours (white, a shadow, a green delta), a regression on BarChart's default. ## For the maintainer (reported, not decided)

Items 8 and 9 are closed by M41 (2026-10-20; ARCHITECTURE.md §23.3): Escape with focus elsewhere is kept as built (item 1), and DonutChart's keyboard is built through the island with a labelled §17.2 raise to 5.3 KiB (item 2; `packages/react/W12-RESULTS.md`).

Each was built the recommended way and can change cheaply before 0.2:

1. **`xDirection="auto"` follows `dir`, not CSS `direction`** (built: mirrored before hydration, no flip on hydration, works with `interaction="none"`). The alternative, following the CSS `direction` property, can only mirror the plot from the island, so an rtl page would draw unmirrored until hydration.
2. **The default `format` is `{}` (Intl's own) in every chart.** The alternative is `{ maximumFractionDigits: 0 }` everywhere, which rounds a 0.45 rate to "0".
3. **The bucketing threshold** stays at about 90 daily points (legibility and keyboard steps); bytes alone would allow about 180.
4. **BarChart before hydration** shows the chart and the hidden table (and `tableView="details"`), with no hover card until the island hydrates, as AreaChart. Rendering the CSS tooltips under `'nizivo'` too and hiding them on hydration would cost island bytes and risk two tooltips.
5. **The card follows the band under the pointer** (both modes): it never disappears while the pointer is over the plot or the card, but a user cannot park the pointer on one bar's card. Pinning it would cost island bytes.
6. **Charts API files carry no slots** (charts parts have no `component.json`), so the slot and data-attribute tables on the docs pages stay hand-written for 0.2.
7. **Label defaults** on the docs pages are hand-written tables; `@default` JSDoc on each label member would let the generated tables carry them.
8. **Escape with focus elsewhere (week 11 review, A11Y-W11-2).** Escape on the focused plot hides only the card. With focus in another control (a pointer-shown card), Escape hides the card and also reaches whatever else listens, so inside a modal dialog it closes the dialog too. Consuming it there as well would follow "Escape closes the innermost layer" but takes an Escape from a control that does not know the card is open.
9. **DonutChart's headroom (week 11 review, R2-4):** 114 B under its 3.2 KiB figure, so its keyboard mode (open) will need a labelled §17.2 raise.
