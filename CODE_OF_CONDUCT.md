# Code of Conduct

Nizivo adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/) as its code of conduct. It applies to everyone taking part in the project: in issues, pull requests, discussions, reviews and any other project space.

## Reporting

Report unacceptable behaviour to the project maintainers at [theneevteam@gmail.com](mailto:theneevteam@gmail.com). Reports are handled in confidence.

Maintainers enforce the code of conduct following the Contributor Covenant's enforcement guidelines.
